# 🛡️ پکیج اصلاح‌شده PXPanel برای عبور از فیلترینگ ایران

این پکیج حاوی سورس اصلاح‌شده پنل PXPanel به همراه اسکریپت ورکر کلودفلر و تنظیمات دپلوی بدون خطا است.

## فایل‌های موجود:
- `main.py`: سورس اصلی پایتون با تفکیک آدرس اتصال، SNI و هدر Host
- `cloudflare_worker.js`: ریورس پروکسی کلودفلر برای رفع فیلترینگ دامنه ریل‌وی
- `requirements.txt`: نیازمندی‌های پایتون
- `railway.json`: تنظیمات دیپلوی خودکار روی Railway

## نحوه استفاده:
1. فایل `main.py` را در ریپازیتوری خود جایگزین کنید.
2. ورکر کلودفلر را بسازید و دامنه ریل‌وی را داخل آن قرار دهید.
3. در کلاینت‌های v2rayNG / NekoBox / MahsaNG:
   - آدرس اتصال: یک آی‌پی تمیز کلودفلر
   - مقدار SNI: دامنه ورکر کلودفلر یا دامنه شخصی شما
   - مقدار Host: دامنه سرور
